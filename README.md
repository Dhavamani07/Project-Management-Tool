Project Management Tool

A simple and user-friendly Project Management Tool developed using Python and Django.

About the Project

This web application helps users manage projects and tasks efficiently. Users can create projects, add tasks, update task status, search tasks, and delete projects or tasks.

Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

Features

- Dashboard with project and task statistics
- Add new projects
- Add new tasks
- Update task status
- Delete projects and tasks
- Search tasks by title
- Filter tasks by status

Project Structure

- "config/" – Django project configuration
- "projects/" – Application files
- "templates/" – HTML pages
- "manage.py" – Django management file

How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install Django:

pip install django

5. Run migrations:

python manage.py migrate

6. Start the server:

python manage.py runserver

7. Open "http://127.0.0.1:8000/" in your browser.
